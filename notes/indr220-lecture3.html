INDR 220 Lecture 3

Algebraic Representation of Optimization Models

Bu derste modelleri bilgisayarın anlayacağı matris/vektör (algebraic) dile çeviriyoruz. Amaç: herhangi bir LP'yi beş nesneye indirgemek: A, b, c, l, u. Sonra çözümün üç olası sonucunu (optimal, infeasible, unbounded) ve quadratic problemlerin matris yazımını göreceğiz.

1. LP'nin matris yazımı

Geçen derslerden LP:

minimize z = c1·x1 + c2·x2 + ... + cN·xN (I) subject to: a11·x1 + a12·x2 + ... + a1N·xN <= b1 (II) a21·x1 + a22·x2 + ... + a2N·xN <= b2 ... aM1·x1 + aM2·x2 + ... + aMN·xN <= bM l1 <= x1 <= u1 (III) ... lN <= xN <= uN

Üç blok var: (I) amaç, (II) kısıtlar, (III) bound'lar. Her birini matris diliyle ifade edeceğiz.

(I) Objective: z = c^T · x

c1·x1 + c2·x2 + ... + cN·xN aslında iki vektörün iç çarpımı (dot product):

c^T · x = [c1 c2 ... cN] · [x1] [x2] = c1·x1 + c2·x2 + ... + cN·xN [..] [xN]

c^T ("c transpoz") bir satır vektörü: 1×N. x bir sütun vektörü: N×1. Çarpım 1×1, yani tek bir sayı. İstediğimiz de tam olarak o: z tek bir sayı.

Transpoz nedir? Sütunu satıra (satırı sütuna) çevirmek. c sütun vektör ise c^T aynı sayıların satır halidir.

(II) Constraint'ler: A · x <= b

Önce tek bir constraint'e bakalım:

a11·x1 + a12·x2 + ... + a1N·xN <= b1

Bu, A'nın birinci satırı ile x'in iç çarpımı:

[a11 a12 ... a1N] · [x1; x2; ...; xN] <= b1 → a1^T · x <= b1

Her constraint için aynısını yaparsak M tane eşitsizlik elde ederiz:

a1^T · x <= b1 a2^T · x <= b2 ... aM^T · x <= bM

Bu satırları alt alta dizip tek matris yaparsak:

[ a1^T ] [ b1 ] A = [ a2^T ] (M x N) b = [ b2 ] (M x 1) [ ... ] [ .. ] [ aM^T ] [ bM ]

ve hepsi birden: A · x <= b

Boyutlara dikkat: A (M×N) · x (N×1) = (M×1) bir vektör, ve bu b (M×1) ile karşılaştırılıyor. (Vektör eşitsizliği: her satır ayrı ayrı kontrol edilir.)

(III) Bound'lar: l <= x <= u

[l1] [x1] [u1] [l2] <= [x2] <= [u2] → l <= x <= u [..] [..] [..] [lN] [xN] [uN]

Hepsi N×1 vektör.

Sonuç: LP'nin kompakt hali

minimize z = c^T · x subject to: A · x <= b l <= x <= u

Çıktı (output): x ∈ R^N (karar değişkenleri) Girdiler (model parameters): c ∈ R^N, A ∈ R^(M×N), b ∈ R^M, l ∈ R^N, u ∈ R^N

Bunu bir fonksiyon gibi düşünebilirsiniz:

def LP_solve(A, b, c, l, u): ... return x

Bu fonksiyonun içini (yani LP'yi gerçekten çözen algoritmayı) birkaç hafta sonra kendimiz yazacağız. Şimdilik "kara kutu" olarak kullanıyoruz.

2. Fabrika örneğini matrislere dökelim

Lecture 01'deki problem:

maximize 3·x1 + 5·x2 subject to: 1·x1 + 0·x2 <= 4 0·x1 + 2·x2 <= 12 3·x1 + 2·x2 <= 18 0 <= x1, 0 <= x2

Adım 1 — Minimize'a çevir (çünkü şablonumuz minimize): minimize -3·x1 - 5·x2

Adım 2 — Sayıları oku:

  • N = 2 (iki değişken), M = 3 (üç constraint)
  • Bound'lar: 0 <= x1 <= +∞, 0 <= x2 <= +∞
[-3] [1 0] [ 4] [0] [+inf] c = [-5] A = [0 2] b = [12] l = [0] u = [+inf] [3 2] [18] (2x1) (3x2) (3x1) (2x1) (2x1)
Sağ taraf (r.h.s.) = right-hand side: b vektörü.

Soru: +∞'yi bilgisayara nasıl yazarız? Bilgisayar sonsuzu "gerçek" bir sayı olarak tutmaz. Pratik çözüm: çok büyük bir sayı kullanmak, örneğin +∞ ≈ 10^20 ve -∞ ≈ -10^20.

Hepsini yan yana:

minimize z = [-3 -5] · [x1] [x2] subject to: [1 0] [x1] [ 4] [0 2] · [x2] <= [12] [3 2] [18] [0] [x1] [+inf] [0] <= [x2] <= [+inf]

Bu 5 nesne (A, b, c, l, u) problemin tamamı. Başka hiçbir şeye gerek yok.

Problem instance ve solution

Problem Instance = { A, b, c, l, u } ⟹ Solution = { x }

"Instance" = belli sayılarla doldurulmuş bir somut problem. Örneğin fabrika problemi bir instance'dır; farklı sayılarla başka bir fabrika problemi başka bir instance'dır.

3. Bir LP'nin üç olası sonucu

Her LP çözülünce üç sonuçtan biri çıkar: optimal, infeasible, unbounded.

a) Optimal

Bir en iyi çözüm bulundu. (Fabrika örneği: x = (2, 6).)

b) Infeasible (uygun çözüm yok)

Constraint'ler birbiriyle çelişir; hiçbir nokta hepsini birden sağlayamaz. Örnek:

minimize 3·x1 + 4·x2 subject to: (A) x1 + x2 <= 4 (B) -x1 - x2 <= -5

(B) eşitsizliğini −1 ile çarpıp yönünü çevirirsek: x1 + x2 >= 5. Yani hem toplam en fazla 4 hem en az 5 olsun diyoruz. Böyle bir sayı yok! Grafikte (A)'nın taralı bölgesi ile (B)'nin taralı bölgesi hiç kesişmiyor: feasible region boş.

Gerçek hayattan benzetme: "Sınavdan hem en fazla 40 hem en az 50 almak istiyorum." Mümkün değil.

c) Unbounded (sınırsız)

Feasible region var ama amaç fonksiyonunu sonsuza kadar iyileştirebilirsin. Örnek:

minimize -3·x1 - 4·x2 subject to: (A) -x1 - x2 <= -5 (yani x1 + x2 >= 5)

Bölge, doğrunun üst-sağ tarafındaki sonsuz bir alan. x1 ve x2'yi büyüttükçe -3x1 - 4x2 sınırsız küçülür (−∞'a gider). "En küçük" diye bir değer yok.

Uyarı: Unbounded sonuç genelde modelleme hatasının işaretidir. Gerçek hayatta kâr sonsuz olamaz; bir constraint'i unutmuş olabilirsin.

4. Quadratic Programming'in matris yazımı

Geçen ders QP'nin amacını Σ ile yazmıştık:

minimize Σ(i=1..N) Σ(j=1..N) qij · xi · xj + Σ(i=1..N) ci · xi └──────── quadratic terms ────────┘ └─── linear terms ──┘

Matris dilinde:

minimize x^T · Q · x + c^T · x (1xN)(NxN)(Nx1) (1xN)(Nx1)
  • Q : N×N katsayı matrisi (qij'leri içerir)
  • x^T Q x boyut olarak 1×1 yani tek sayı ✔.

Küçük bir not

a^T · b = a^T · I · b yazabiliriz (I = birim matris, identity). Yani çarpımın ortasındaki I hiçbir şeyi değiştirmiyor; Q'yu "ortaya konan matris" olarak düşünebilirsin: Q=I ise sıradan iç çarpım.

Örnek: (x1 + x2)² ifadesinin Q matrisi

Önce açalım:

(x1 + x2)² = (x1 + x2)(x1 + x2) = 1·x1² + 1·x1·x2 + 1·x2·x1 + 1·x2² = q11·x1² + q12·x1·x2 + q21·x2·x1 + q22·x2²

Katsayıları yan yana okuyunca q11 = q12 = q21 = q22 = 1:

Q = [1 1] [1 1]

Kontrol (çarpalım):

[x1 x2] · [1 1] · [x1] = [x1 x2] · [x1 + x2] = x1·(x1+x2) + x2·(x1+x2) [1 1] [x2] [x1 + x2] = x1² + x1·x2 + x2·x1 + x2² ✔

Q tek değildir! (Önemli gözlem)

Tahtada aynı ifade için başka matrisler de denendi:

Q = [1 2] → x1² + 2·x1·x2 + x2² [0 1] Q = [ 1 4] → x1² + 4·x1·x2 − 2·x1·x2 + x2² = x1² + 2·x1·x2 + x2² [-2 1]

Üçü de aynı fonksiyonu veriyor! Çünkü fonksiyonda x1·x2 ile x2·x1 aynı terimdir; önemli olan sadece q12 + q21 toplamı (burada 2). Bu toplam aynı kaldıkça Q'nun kendisi farklı olabilir. Yani bir kuadratik fonksiyonu temsil eden birden fazla Q var.

Faydalı kısayollar

Σ(i=1..N) xi = [1 1 ... 1] · x = 1^T · x (1 = hepsi bir olan vektör) Σ(i=1..N) xi² = [x1 ... xN] · x = x^T · x

Yani x^T · x = xi²'lerin toplamı (vektörün kendisiyle iç çarpımı).

Örnek: iki nokta arasındaki mesafeyi minimize etmek

İki nokta: (x1, y1) ve (x2, y2). Mesafe (Pisagor):

distance = sqrt( (x1 - x2)² + (y1 - y2)² )

Kare kök bir doğrusal olmayan fonksiyon, işi zorlaştırır. Ama mesafeyi minimize etmek ile mesafenin karesini minimize etmek aynı noktada biter (çünkü mesafe ≥ 0 iken kare alma işlemi sıralamayı bozmaz: küçük olan hâlâ küçük kalır). O yüzden:

minimize distance ⟺ minimize distance² ⟺ minimize (x1 - x2)² + (y1 - y2)² = x1² − 2·x1·x2 + x2² + y1² − 2·y1·y2 + y2²

Bu, değişken vektörü [x1 x2 y1 y2]^T için bir kuadratik fonksiyon, ve Q şu:

Q = [ 1 -1 0 0] [-1 1 0 0] [ 0 0 1 -1] [ 0 0 -1 1]

Kendin kontrol et: x^T Q x'i açarsan yukarıdaki ifade çıkıyor.

Çıkarım: Bir şeyin doğrusal olmayan hâlini (kare kök) onunla aynı yerde minimum yapan daha kolay bir hâliyle (kare) değiştirmek, modellemede sık kullanılan bir hiledir.

Özet

  • Her LP, 5 nesneyle tanımlanır: c, A, b, l, u. Problem instance = {A, b, c, l, u}; solution = {x}.
  • Objective: c^T x. Constraint'ler: A x <= b. Bound'lar: l <= x <= u.
  • Maximize → önce −1 ile çarp, minimize yap. ±∞ yerine ±10^20.
  • Üç olası sonuç: optimal, infeasible, unbounded.
  • QP objective: x^T Q x + c^T x. Q tek değil; sadece qij + qji toplamları önemli.

Kendini test et

  1. minimize 2x1 + 3x2, subject to x1 + x2 <= 10, x1 >= 0, x2 >= 0 problemini (c, A, b, l, u) olarak yaz. Çözüm ne olurdu, tahmin et.
  2. x1 >= 3 kısıtını A x <= b biçimine nasıl çevirirsin?
  3. x1² + 6·x1·x2 + 4·x2² için bir Q matrisi bul.
Cevapları Gör
  1. c = [2, 3]^T, A = [[1, 1]], b = [10], l = [0, 0]^T, u = [+inf, +inf]^T. Maliyeti küçültmek istiyoruz ve alt sınır 0 olduğu için x = (0, 0) optimal (z = 0).
  2. İki tarafı −1 ile çarp, yön değişir: -x1 <= -3. (A'ya satır olarak [-1, 0], b'ye −3 eklenir.) Ya da bound olarak yaz: 3 <= x1.
  3. Örneğin Q = [[1, 3],[3, 4]] (q12 + q21 = 6) ya da Q = [[1, 6],[0, 4]]. İkisi de olur.
