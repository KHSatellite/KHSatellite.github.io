Final Sınavı — Çözümlü Pratik Soruları

Tahtaya yazılan sınav yapısına göre hazırlanmış, çözümlü örnek sorular. Her soru tipini birden fazla versiyonla çalış.

Bölüm A — B/C Analizi (Q1 Tipi, ~15 dk)

B/C sorularında genellikle büyük bir tablo verilir, faydalar/masraflar aylık ya da yıllık karışık biçimde sunulur. Tümünü aynı bazda topla, artımsal prosedürü uygula.

Soru A-1 — Bağımsız Proje (Basit)

Bir kamu karayolu projesinin verileri: İnşaat maliyeti $P = \$4{,}000{,}000$, yıllık bakım $M\&O = \$150{,}000$, proje ömrü $n = 20$ yıl, $i = \%8$. Yıllık fayda (taşıt süresi tasarrufu) $B = \$600{,}000$, yıllık disbenefit (gürültü) $D = \$50{,}000$. Konvansiyonel B/C = ? Proje kabul edilmeli mi?

Çözümü Gör
$(A/P,8\%,20) = 0.10185$
$C = P(A/P) + M\&O = 4{,}000{,}000(0.10185) + 150{,}000 = 407{,}400 + 150{,}000 = \$557{,}400/\text{yıl}$
$B/C = \dfrac{B - D}{C} = \dfrac{600{,}000 - 50{,}000}{557{,}400} = \dfrac{550{,}000}{557{,}400} = \mathbf{0.987}$
$0.987 < 1$ → Reddedilir.
Soru A-2 — İki ME Alternatif, Aylık Dönüşüm (Tahtaya Benzer)

İki köprü alternatifi, $i = \%6$, $n = 30$ yıl. Aşağıdaki tablo verilmiştir:

Çözümü Gör

$M\&O_1 = 15000 \times 12 = \$180{,}000/\text{yıl}$
$M\&O_2 = 8000 \times 12 = \$96{,}000/\text{yıl}$
$D_1 = 5000 \times 12 = \$60{,}000/\text{yıl}$
$D_2 = 3000 \times 12 = \$36{,}000/\text{yıl}$

Adım 2 — AW (yıllık maliyet) bazında C hesabı:
$(A/P,6\%,30) = 0.07265$
$C_1 = 8{,}000{,}000(0.07265) + 180{,}000 = 581{,}200 + 180{,}000 = \$761{,}200/\text{yıl}$
$C_2 = 14{,}000{,}000(0.07265) + 96{,}000 = 1{,}017{,}100 + 96{,}000 = \$1{,}113{,}100/\text{yıl}$

Adım 3 — Sırala (artan C): Alt1 ($761k) → Alt2 ($1113k)

Adım 4 — DN vs Alt1:
$B/C_1 = (1{,}200{,}000 - 60{,}000)/761{,}200 = 1{,}140{,}000/761{,}200 = 1.497 \geq 1$ → Alt1 aday

Adım 5 — Alt1 vs Alt2 (artımsal):
$\Delta C = C_2 - C_1 = 1{,}113{,}100 - 761{,}200 = \$351{,}900/\text{yıl}$
$\Delta B = (B_2 - D_2) - (B_1 - D_1) = (1{,}800{,}000-36{,}000)-(1{,}200{,}000-60{,}000)$
$= 1{,}764{,}000 - 1{,}140{,}000 = \$624{,}000/\text{yıl}$
$\Delta B/C = 624{,}000/351{,}900 = 1.773 \geq 1$ → Alt2 seçilir.

Soru A-4 — Değiştirilmiş B/C

Bir su arıtma tesisi: $P=\$5{,}000{,}000$, $n=30$ yıl, $i=\%7$. Yıllık M&O=$\$200{,}000$, yıllık fayda=$\$900{,}000$, yıllık disbenefit=$\$70{,}000$. Değiştirilmiş B/C = ?

Çözümü Gör
$(A/P,7\%,30) = 0.08059$
$CR = 5{,}000{,}000(0.08059) = \$402{,}950/\text{yıl}$
Değiştirilmiş $B/C = \dfrac{B - D - M\&O}{CR} = \dfrac{900{,}000 - 70{,}000 - 200{,}000}{402{,}950} = \dfrac{630{,}000}{402{,}950} = \mathbf{1.563}$
$\geq 1$ → Kabul edilir.

Tahtadaki GERÇEK Sınav Sorusu (Q2):

Soru B-1 — TAHTADAKİ SORUNUN ÇÖZÜMÜ ★

Alt 1: $P_1=23{,}000$, $S_1=4{,}000$, $AOC_1=3{,}500$, kapasite=8 ton/saat, işçilik=$12/saat, $n_1=10$
Alt 2: $P_2=8{,}000$, $S_2=0$, $AOC_2=1{,}500$, kapasite=6 ton/saat, işçilik=$24/saat, $n_2=5$, $i=10\%$

Tam Çözümü Gör
Adım 1 — Faktörler (i=%10):
$(A/P,10\%,10) = 0.16275$,   $(A/F,10\%,10) = 0.06275$
$(A/P,10\%,5) = 0.26380$

Adım 2 — Capital Recovery:
$CR_1 = (23{,}000-4{,}000)(0.16275) + 4{,}000(0.10) = 19{,}000 \times 0.16275 + 400 = 3{,}092.25 + 400 = \$3{,}492.25/\text{yıl}$
$CR_2 = (8{,}000-0)(0.26380) + 0 = \$2{,}110.40/\text{yıl}$

Adım 3 — İşçilik maliyeti (X ton/yıl cinsinden):
$X$ ton/yıl üretmek için çalışma süresi:
Alt 1: $X/8$ saat/yıl → işçilik $= 12 \times (X/8) = 1.5X$ $/yıl
Alt 2: $X/6$ saat/yıl → işçilik $= 24 \times (X/6) = 4X$ $/yıl

Adım 4 — Toplam AW:
$AW_1 = 3{,}492.25 + 3{,}500 + 1.5X = \mathbf{6{,}992.25 + 1.5X}$
$AW_2 = 2{,}110.40 + 1{,}500 + 4X = \mathbf{3{,}610.40 + 4X}$

Adım 5 — Eşitle:
$6{,}992.25 + 1.5X = 3{,}610.40 + 4X$
$3{,}381.85 = 2.5X$
$$\boxed{X_{BE} = \frac{3{,}381.85}{2.5} \approx 1{,}353 \text{ ton/yıl}}$$ Karar:
$X > 1{,}353$ ton/yıl → Alt 1 (büyük makine, tek işçi) daha ucuz → Seç
$X < 1{,}353$ ton/yıl → Alt 2 daha ucuz

Doğrulama @ X=1353:
$AW_1 = 6{,}992.25 + 1.5(1{,}353) = 6{,}992 + 2{,}030 = \$9{,}022$
$AW_2 = 3{,}610.40 + 4(1{,}353) = 3{,}610 + 5{,}412 = \$9{,}022$ ✓

Soru E-3 — Q5 Tipi: "Neden Bir Alternatif Diğerinden İyi?" Yazılı Soru

Alt A (AW=$\$22{,}000$/yıl) seçildi, Alt B (AW=$\$28{,}000$/yıl) reddedildi. (a) Kararı sayısal olarak gerekçelendir. (b) 10 yıllık çalışma süresinde seçim kaç dolarlık tasarruf sağlar ($i=\%12$)? (c) Bu tasarrufun bugünkü değeri nedir?

Çözümü Gör
(a) A seçilir çünkü $AW_A = \$22{,}000/\text{yıl} < AW_B = \$28{,}000/\text{yıl}$.
Yıllık $\$6{,}000$ daha az maliyet. AW yöntemi farklı ömürlü alternatifleri otomatik karşılaştırır.

(b) Nominal toplam tasarruf (time value yoksayılırsa):
$6{,}000 \times 10 = \$60{,}000$ (sadece nominal, yanıltıcı)

(c) Yıllık $\$6{,}000$ tasarrufun bugünkü değeri:
$(P/A,12\%,10)=5.6502$
$PW_{\text{tasarruf}} = 6{,}000 \times 5.6502 = \$33{,}901$
Yani bugün $\$33{,}901$ ödeyerek A'yı seçmek ekonomik açıdan haklıdır.
